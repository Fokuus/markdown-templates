# Markdown templates

A small set of ready-to-use Markdown templates: a project README, a one-page CV, a
technical spec, and meeting notes. Copy one, fill in your content, done.

Everything here is plain Markdown, so it works anywhere: on GitHub, in your editor, on a
static site, or as a PDF.

## Turn any of these into a PDF

These templates are written to print well. To get a clean PDF (or just print) without
installing anything, paste the Markdown into [mdprint.app](https://mdprint.app) and export.
It runs entirely in your browser, so the file never leaves your device, and it keeps tables,
code highlighting, math (KaTeX) and Mermaid diagrams. The
[technical spec](templates/technical-spec.md) is a good one to try, since it uses all of those.

If you prefer the command line, tools like `pandoc` or `md-to-pdf` work too.
